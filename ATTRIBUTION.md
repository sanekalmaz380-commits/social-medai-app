# Attribution & External Assets

Проект **MedReminder AI** построен на базе веб-стандартов и не использует сторонние проприетарные библиотеки.

## Использованные веб-стандарты и браузерные API:
- **Web Speech API (`SpeechSynthesis`)** — встроенная технология браузера для озвучивания текста (W3C Standard).
- **HTML5 Web Storage API (`localStorage`)** — локальное хранение данных в браузере пользователя без использования внешних серверов.
- **WAI-ARIA (Accessibility Standards)** — семантические атрибуты доступности для корректного чтения скринридерами (WCAG AAA).

## Лицензирование компонентов
Весь исходный код приложения, UI-адаптация и логика взаимодействия с пользователем разработаны с нуля и распространяются под лицензией [MIT](LICENSE).
