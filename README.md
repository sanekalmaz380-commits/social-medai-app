# 🏥 MedReminder AI — Социальный помощник по приему лекарств

> Доступный веб-сервис для старшего поколения и людей с ограничениями зрения.

![Demo Screen](docs/demo.png)

## 📌 Описание проблемы и решения
Пожилым людям часто трудно ориентироваться в сложных интерфейсах современных приложений. **MedReminder AI** решает эту проблему за счет контрастного интерфейса, голосовых подсказок (Web Speech API) и упрощенного сценария взаимодействия в 1 клик.

## 🚀 Основные возможности
- 🔊 **Голосовое сопровождение действий:** автоматическое озвучивание добавления, удаления и подтверждения лекарств.
- 👁️ **Высококонтрастный режим (WCAG AAA):** крупный шрифт, четкие границы элементов и сочные кнопки.
- ⏰ **Уведомления и подтверждения:** хранение списка приема в локальной памяти браузера (`localStorage`).
- 📱 **Адаптивный интерфейс:** удобное управление как с мобильного телефона, так и с ПК.

## 🛠️ Технологический стек
- **Frontend:** HTML5, CSS3 (EasyUI theme), JavaScript (ES6+)
- **Accessibility:** Web Speech API (`SpeechSynthesis`), ARIA-метки
- **Storage:** Web Storage API (`localStorage`)
